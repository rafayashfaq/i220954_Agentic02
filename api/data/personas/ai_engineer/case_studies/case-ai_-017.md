# Case Study: Medical entity recognition with clinical BERT and spaCy (case-ai_-017)
**Client Industry**: FinTech
**Duration**: 2 weeks
**Skills**: LangGraph, Python, Fine-tuning, FastAPI
**Outcome**: Delivered on budget; client achieved 46% efficiency improvement.

## Problem Statement
The client required a production-grade solution for medical entity recognition with clinical bert and spacy. Existing legacy systems suffered from high maintenance costs, lack of test coverage, and performance bottlenecks under peak load.

## Technical Solution
Implemented using LangGraph and Python. Architected modular components with strict schema validation and automated integration tests. Designed for zero-downtime deployment and comprehensive observability.

## Measured Outcomes
- Latency reduced by 34%.
- System throughput increased to 4863 RPS.
- Client rating: 5.0/5.0 with stellar recommendation.
