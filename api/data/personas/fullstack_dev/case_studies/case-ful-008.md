# Case Study: Automated video rendering pipeline with Next.js and Remotion (case-ful-008)
**Client Industry**: EdTech
**Duration**: 7 weeks
**Skills**: Redis, Docker, Node.js, PostgreSQL
**Outcome**: Delivered on budget; client achieved 60% efficiency improvement.

## Problem Statement
The client required a production-grade solution for automated video rendering pipeline with next.js and remotion. Existing legacy systems suffered from high maintenance costs, lack of test coverage, and performance bottlenecks under peak load.

## Technical Solution
Implemented using Redis and Docker. Architected modular components with strict schema validation and automated integration tests. Designed for zero-downtime deployment and comprehensive observability.

## Measured Outcomes
- Latency reduced by 61%.
- System throughput increased to 4171 RPS.
- Client rating: 5.0/5.0 with stellar recommendation.
