# Case Study: Role-based access control (RBAC) and OAuth2 / SSO authentication service (case-ful-019)
**Client Industry**: B2B SaaS
**Duration**: 3 weeks
**Skills**: Redis, Docker, Tailwind CSS, Next.js
**Outcome**: Delivered on budget; client achieved 33% efficiency improvement.

## Problem Statement
The client required a production-grade solution for role-based access control (rbac) and oauth2 / sso authentication service. Existing legacy systems suffered from high maintenance costs, lack of test coverage, and performance bottlenecks under peak load.

## Technical Solution
Implemented using Redis and Docker. Architected modular components with strict schema validation and automated integration tests. Designed for zero-downtime deployment and comprehensive observability.

## Measured Outcomes
- Latency reduced by 75%.
- System throughput increased to 2816 RPS.
- Client rating: 5.0/5.0 with stellar recommendation.
