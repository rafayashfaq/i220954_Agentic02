# Case Study: Role-based access control (RBAC) and OAuth2 / SSO authentication service (case-ful-009)
**Client Industry**: Marketplaces
**Duration**: 4 weeks
**Skills**: React, FastAPI, Node.js, Docker
**Outcome**: Delivered on budget; client achieved 57% efficiency improvement.

## Problem Statement
The client required a production-grade solution for role-based access control (rbac) and oauth2 / sso authentication service. Existing legacy systems suffered from high maintenance costs, lack of test coverage, and performance bottlenecks under peak load.

## Technical Solution
Implemented using React and FastAPI. Architected modular components with strict schema validation and automated integration tests. Designed for zero-downtime deployment and comprehensive observability.

## Measured Outcomes
- Latency reduced by 67%.
- System throughput increased to 3523 RPS.
- Client rating: 5.0/5.0 with stellar recommendation.
