# Case Study: Automated financial ETL pipeline extracting Stripe and QuickBooks data (case-dat-018)
**Client Industry**: Gaming
**Duration**: 7 weeks
**Skills**: Pandas, Looker, Statistical Modeling, Snowflake
**Outcome**: Delivered on budget; client achieved 55% efficiency improvement.

## Problem Statement
The client required a production-grade solution for automated financial etl pipeline extracting stripe and quickbooks data. Existing legacy systems suffered from high maintenance costs, lack of test coverage, and performance bottlenecks under peak load.

## Technical Solution
Implemented using Pandas and Looker. Architected modular components with strict schema validation and automated integration tests. Designed for zero-downtime deployment and comprehensive observability.

## Measured Outcomes
- Latency reduced by 69%.
- System throughput increased to 3147 RPS.
- Client rating: 5.0/5.0 with stellar recommendation.
