# Case Study: Automated financial ETL pipeline extracting Stripe and QuickBooks data (case-dat-008)
**Client Industry**: Supply Chain
**Duration**: 3 weeks
**Skills**: BigQuery, Pandas, Statistical Modeling, Power BI
**Outcome**: Delivered on budget; client achieved 47% efficiency improvement.

## Problem Statement
The client required a production-grade solution for automated financial etl pipeline extracting stripe and quickbooks data. Existing legacy systems suffered from high maintenance costs, lack of test coverage, and performance bottlenecks under peak load.

## Technical Solution
Implemented using BigQuery and Pandas. Architected modular components with strict schema validation and automated integration tests. Designed for zero-downtime deployment and comprehensive observability.

## Measured Outcomes
- Latency reduced by 37%.
- System throughput increased to 3327 RPS.
- Client rating: 5.0/5.0 with stellar recommendation.
